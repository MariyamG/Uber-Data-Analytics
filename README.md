# Uber-Data-Analytics

This is an end to end Data engineering project 
The components/tech stack used are
- Google Cloud Storage
- Google Cloud Compute to host the Mage cluster
- Mage , An Open source ETL tool for DE
- Looker Studio , for visualization
- LucidChart , for data modelling

Caveat : In this project ,we have added the passenger_cnt as a separate dimension but in reality this is actually a fact since this is numeric, additive and changes over time.
